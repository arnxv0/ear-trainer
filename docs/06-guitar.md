# 06. Guitar: from "I know the chords" to playing them

The user plays guitar. Every chord answer in the app should end in a shape his hands can play, in the real key of the song.

## Voicings

Source options, in order:
1. **chords-db** (`github.com/tombatossals/chords-db`): JSON guitar voicings for all keys and many suffixes. Check its license before bundling. If acceptable, use it as the primary source.
2. **Generator fallback** in `theory/voicings`:
   - Open chord table for common shapes (C, A, G, E, D and their m, 7, maj7, m7, sus2, sus4, add9 variants). Hand-written, about 60 entries.
   - Movable barre shapes generated by transposition: E-shape and A-shape for maj, m, 7, maj7, m7, m7b5, dim7, sus4, 9, m9, 6, m6, add9. Also C-shape and D-shape for extended chords where E/A shapes are awkward.
   - Slash chords: base voicing with the bass moved to the required note on the lowest string played, if reachable within the shape; otherwise show "play X, bass plays Y".
   - Each voicing: frets per string (x for muted), fingers, base fret, difficulty score (barre, stretch, fret position).

For each chord show up to 3 voicings sorted by: open first, then lowest difficulty, then position close to the previous chord in the progression (minimise hand movement).

## Capo suggestion

Given a progression in a key, for capo 0 to 7, transpose the chord shapes down by the capo amount and count how many become open shapes from the table. Suggest the capo with the most open shapes, ties broken by lower capo. Show: "Capo 1, play as G major: G D Em C".

## Fretboard component

- Shows a voicing (dots, fingers, muted/open markers) or highlights note positions.
- Tonic finder mode (T6, G2): tap any fret to hear that note while the clip is paused; when the user marks a fret as tonic, compare its pitch class to the corpus tonic.
- Scale overlay: show all positions of the current key's scale degrees, labelled with degrees. Used in reveal screens so the user connects degree to fret.

## Lab chord sound

Play chords using the same voicing shown, through a guitar soundfont, strummed (stagger string onsets by 15 to 30 ms down or up). This makes Lab chords sound like his guitar, which helps transfer.

## Play Along

See 03. Key pieces here: current and next chord voicings side by side, beat count-in, loop of the bar range, speed 0.75x / 1x, capo toggle, hide-chords toggle for ear-only play.

## Guitar-specific drills (track G)

- **Hear and fret (G2, T6):** clip loops, user finds the tonic on the real guitar, then taps it on the fretboard UI to confirm.
- **Shape the progression (G3):** after naming a 4-chord loop in Bridge, the app shows voicings and loops the clip for play along.
- **Strum check (G4, optional):** mic chroma check per chord (04).
- **Transpose by ear:** play the progression shown in numerals in a new key the app names. Builds the numeral to shape link so "I-V-vi-IV in B" becomes instant.

## Modes on guitar

When a song is modal (Dorian, Mixolydian, Lydian, Phrygian), the reveal screen also shows:
- The characteristic chord (Dorian IV, Mixolydian bVII, Lydian II, Phrygian bII) highlighted.
- The scale on the fretboard with the characteristic note (Dorian 6, Mixolydian b7, Lydian #4, Phrygian b2) marked.
This ties the modal sound to a chord and a fret position the user can play immediately.
